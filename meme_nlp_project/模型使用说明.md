# 模型使用说明

## 训练后的模型位置

RoBERTa 模型保存在：

```text
C:\Users\zhao\Desktop\自然语言处理\meme_nlp_project\models\roberta
```

其中：

- `models\roberta\has_meme`：判断文本是否包含网络热梗。
- `models\roberta\sentiment`：判断热梗文本的情绪是正向、中性还是负向。
- `models\roberta\test_predictions.csv`：测试集预测结果。

当前版本使用 702 条样本训练，其中热梗样本 522 条、普通样本 180 条，
热梗词典 366 条。训练轮数为 6，情绪分类使用类别权重，并对常见热梗补充了
正向、中性、负向三种语境的对照样本。

当前测试结果：

- 热梗识别：accuracy 1.0000，macro-F1 1.0000。
- 情绪分类：accuracy 0.6667，macro-F1 0.6420。
- 负向情绪：precision 0.5556，recall 0.6250，F1 0.5882。

旧版本仍保留在：

```text
models\roberta_412_backup
models\roberta_612_before_sentiment_fix
```

## 最简单的使用方法

双击项目根目录下的：

```text
运行热梗预测.bat
```

输入一句中文文本并按回车，终端会返回：

- `has_meme`：是否包含热梗。
- `sentiment`：情绪类别。
- `matched_memes`：命中的热梗及词典释义。

## 使用 PowerShell 指令

先进入项目目录：

```powershell
cd "C:\Users\zhao\Desktop\自然语言处理\meme_nlp_project"
```

然后运行：

```powershell
& ".\.venv\Scripts\python.exe" -m scripts.predict `
  --model roberta `
  --model-dir models\roberta `
  --text "这部电影yyds，但我有点emo。"
```

输出示例：

```json
{"has_meme": "yes", "sentiment": "中性", "text": "这部电影yyds，但我有点emo。", "matched_memes": [{"meme": "yyds", "category": "缩写类", "meaning": "永远的神，形容非常厉害"}, {"meme": "emo", "category": "情绪状态类", "meaning": "情绪低落、伤感"}]}
```

## 新增未收录热梗

网页会把识别到、但词典尚未命中的表达显示为“新梗模式识别”。
此时可以在结果下方填写类别和释义，点击“加入词典”。

用户新增内容保存在：

```text
data\manual\dictionary_overrides.csv
```

文件统一使用以下四列格式：

```text
meme,category,meaning,example
```

提交成功后当前网页会立即重新分析，并优先按词典命中处理。
只新增词条和释义不需要重新训练模型；如果希望模型也学习该词的上下文用法，则需要补充样本并重新训练。

## 一次预测多句

重复添加 `--text` 参数即可：

```powershell
& ".\.venv\Scripts\python.exe" -m scripts.predict `
  --model roberta `
  --model-dir models\roberta `
  --text "这部电影yyds。" `
  --text "这锅我来背。"
```

## 说明

当前 PyTorch 为 CPU 版本，模型可以直接运行。电脑有 RTX 4080，如果需要显著加快训练，可以在项目虚拟环境中安装对应 CUDA 版本的 PyTorch；预测阶段即使使用 CPU 也可以完成。

## 重新训练

先重新生成数据划分：

```powershell
& ".\.venv\Scripts\python.exe" scripts\prepare_data.py
```

再训练 RoBERTa：

```powershell
& ".\.venv\Scripts\python.exe" -m scripts.model_pipeline `
  --model roberta `
  --output-dir models\roberta `
  --pretrained-model models\roberta_base `
  --epochs 6 `
  --batch-size 8 `
  --max-length 64 `
  --learning-rate 2e-5
```

训练指标写入 `reports\roberta_metrics.json`，测试集逐句结果写入
`models\roberta\test_predictions.csv`。
